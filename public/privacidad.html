Política de privacidad

Mis Finanzas · Última actualización: 28 de septiembre de 2026

Mis Finanzas es una aplicación de finanzas personales de uso privado. La usa únicamente su propietario y las personas autorizadas expresamente. No es un servicio comercial, no tiene publicidad y no vende ni comparte datos con terceros con fines comerciales.

Qué datos de Google usa la aplicación

Con tu autorización, la aplicación accede a tu cuenta de Gmail con el permiso https://www.googleapis.com/auth/gmail.modify para:

  • Buscar y leer solo los correos de los remitentes bancarios que configuras en la aplicación (y, si la activas, los que tienen la etiqueta de Gmail que indicas).
  • Quitar esa etiqueta de los correos ya procesados. Por eso se requiere gmail.modify y no un permiso de solo lectura. La aplicación no envía, borra ni reenvía correos.

Para el inicio de sesión con Google, la aplicación usa tu nombre, tu correo y tu foto de perfil para identificarte y verificar que estás en la lista de usuarios autorizados.

Para qué se usan

El texto de los correos bancarios se usa exclusivamente para extraer los datos de cada movimiento (monto, comercio, fecha, cuenta o tarjeta, categoría) y registrarlos en tu historial financiero dentro de la aplicación. No se usan para ningún otro propósito.

Con quién se comparten

  • Google Gemini API: el asunto, el remitente y el texto de cada correo bancario se envían a la API de Gemini para interpretar el movimiento. Se rige por los términos de la API de Gemini.
  • Firebase / Google Cloud: los movimientos, la configuración y el token de autorización de Gmail se almacenan en Cloud Firestore, dentro del proyecto de Firebase del propietario.

No se comparten datos con ninguna otra persona o servicio.

Almacenamiento y seguridad

  • Solo las cuentas de Google que están en la lista de usuarios autorizados pueden ver o modificar los datos financieros; lo garantizan las reglas de seguridad de Firestore.
  • El token de acceso a Gmail se guarda en una colección que la aplicación web no puede leer; solo lo usa el proceso automático del propietario, con credenciales de servidor.
  • Las comunicaciones se hacen siempre por conexiones cifradas (HTTPS).

Conservación y eliminación

Los movimientos se conservan mientras el propietario los mantenga en la aplicación y se pueden eliminar en cualquier momento desde ella. Puedes retirar el acceso a tu Gmail cuando quieras en myaccount.google.com/permissions; desde ese momento la aplicación deja de leer tus correos.

Uso limitado. El uso que hace Mis Finanzas de la información recibida de las API de Google, y su transferencia a cualquier otra aplicación, cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cambios y contacto

Si esta política cambia, se actualizará en esta misma página con una nueva fecha. Para cualquier pregunta, escribe al correo de asistencia que aparece en la pantalla de autorización de Google de esta aplicación.
